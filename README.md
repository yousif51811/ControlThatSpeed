# 🏃 Control That Speed!

A lightning-fast PumpkinMC plugin (Get it?) to control different player speed attributes

## How to use

```
/speed <type> <multiplier> [<players>]
```

Types are:

- Fly Speed
- Movement speed
- Sneaking speed
- Mining speed
- Submerged mining speed

## Editable attributes

### Fly speed

`/flyspeed` `/fs` `/speed fly`

### Movement speed

`/movementspeed`, `/movespeed`, `/ms`, `/speed movement`

### Sneaking speed

`/sneakspeed` `/ss` `/speed sneak`

### Mining speed

`/minespeed` `/ms` `/speed mine`

### Underwater mining speed

`/submergedminespeed` `/sms` `/speed submerged_mine`
